# Pikmintro
A Pikmin-themed retexture mod for Balatro!

Adds in custom pixel art for all Jokers, Tarot cards, Planet cards, Spectral cards, Vouchers, Booster Packs, Decks, Seals, most Blinds, and some Tags, all of which reference the Pikmin series! Also adds a set of Pikmin-character face cards, which can be accessed from Options -> Customize Deck.

Requires [Steamodded](https://github.com/Steamodded/smods) and the latest commit of [Malverk](https://github.com/Eremel/Malverk).

Note: Once Malverk and Pikmintro are active from the Mods menu, make sure to go to Options -> Textures to apply the Pikmintro texture pack!

This mod does not change any code or add any features to gameplay, though it does rename most objects in the game with Pikmin-themed names, and it changes the background colors of Boss Blinds to reflect their custom textures. As such, it may be prone to conflicts with other mods.
